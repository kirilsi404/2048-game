# 2048 (Console C++)

A terminal-based clone of **2048** written in C++ for my Introduction to Programming practicum at Sofia University (FMI).

---

## How to Play

Slide tiles across a nxn grid, where n could be from 4 to 10. When two tiles with the same number collide, they merge into one with double the value.

- **Controls:** `W` (Up), `A` (Left), `S` (Down), `D` (Right) *(or your game's keys)*
- **Spawns:** After each move, a new `2` (90%) or `4` (10%) appears in an empty space.
- **Goal:** Reach the **2^k** tile before the board fills up and no moves remain.
